Arsitektur vintage-memories-scrapbook

Situs statis penuh, tanpa build. Satu halaman HTML (root = produk); media lokal di repo (±7 MB); tidak ada dependensi produksi npm. Deploy = unggah direktori ke Cloudflare Pages.

Alur scrapbook: start-overlay → klik "Buka Kado Cinta" (audio.play, unlock autoplay) → slide 1–5 via tombol Lanjut/Kembali, gerbang bunga mengunci navigasi ±1,85 detik → slide 4 amplop (klik → segel pecah, surat naik, ketik) → slide 5 tombol hati (20 partikel).
